Closed Shadow Root — Keyboard AT fixture

A custom element with a closed shadow root containing a focusable element. The engine MUST NOT introspect into closed shadow roots, so the inner element should not appear on the COLLECT_INTERACTIVE_ELEMENTS_DATA screen. A light-DOM control button is included as a baseline so the engine still detects at least one interactive element.
