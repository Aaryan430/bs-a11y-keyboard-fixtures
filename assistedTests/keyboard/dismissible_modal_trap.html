Dismissible Modal Trap — Keyboard AT fixture

Tab-reachable controls plus a modal that opens immediately on load. The modal traps Tab focus inside itself so the AT's tab-scan surfaces the trap-confirmation prompt. The user can dismiss the modal either via Escape (keyboard) or by clicking outside the card (mouse), so test cases can confirm any of:

  • Option 1: "I exited the trap using only keyboard" — user pressed Escape
  • Option 2 → "I exited the trap using other means" — user clicked outside
  • Option 3: "There is no focus trap" — modal is intentional, user overrides engine
